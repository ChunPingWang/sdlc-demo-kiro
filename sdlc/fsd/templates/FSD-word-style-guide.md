## 2. 樣式定義

| 樣式名稱 | 用途 | 字型 | 字級 | 粗體 | 顏色 | 段前間距 | 段後間距 |

## 4. 表格樣式

### 4.1 標準表格

- **標頭列：** 背景色 `#1F3864`，文字白色，字型微軟正黑體 9pt 粗體
- **奇數資料列：** 背景色 `#FFFFFF`（白）
- **偶數資料列：** 背景色 `#EEF3FA`（淺藍）
- **框線：** 外框 1pt 實線 `#1F3864`；內線 0.5pt 實線 `#B4C6E7`
- **儲存格邊距：** 上下 0.1 cm，左右 0.2 cm

### 4.2 需求追蹤表

- 延伸自標準表格
- 「優先等級」欄位條件格式：
  - 高 → 背景 `#FF0000`（紅），文字白色
  - 中 → 背景 `#FFC000`（橙），文字黑色
  - 低 → 背景 `#92D050`（綠），文字黑色

## 5. 章節編號規則

採用 Word **多層清單樣式** 自動編號，格式如下：

```
第 1 章  文件目的與範圍
  1.1   目的
  1.2   範圍
    1.2.1  功能範圍
    1.2.2  非功能範圍
第 2 章  名詞定義
  ...
```

- 章節標題自動加入**目錄**（目錄顯示至第 3 層）
- 圖表編號格式：`圖 {章節}-{序號}`（例：圖 5-1）、`表 {章節}-{序號}`（例：表 3-2）

## 7. 從 Markdown 轉換為 Word 的作業步驟

### 方式一：Pandoc 指令（推薦）

```bash
pandoc FSD-output.md \
  --reference-doc=FSD-template.docx \
  --toc \
  --toc-depth=3 \
  --output=FSD-{PROJECT_CODE}-{VERSION}.docx
```

> **前置需求：** 安裝 [Pandoc](https://pandoc.org/) 與參考套版 `FSD-template.docx`。  
> 套版檔案須預先設定好第 2 節所定義的所有樣式。

### 方式二：手動套版

1. 以 Word 開啟 `FSD-template.docx`
2. 另存新檔為 `FSD-{PROJECT_CODE}-{VERSION}.docx`
3. 將 Markdown 內容複製後，使用 **保留來源格式貼上**
4. 逐章套用本指南定義的 Word 樣式
5. 更新目錄：選取目錄 → 右鍵 → **更新欄位** → **更新整個目錄**
6. 驗證頁首頁尾資訊是否正確填寫

## 8. 輸出命名規則

```
FSD-{PROJECT_CODE}-v{MAJOR}.{MINOR}.docx

範例：
  FSD-ECOM-v1.0.docx    （初版）
  FSD-ECOM-v1.2.docx    （第二次修訂）
  FSD-ECOM-v2.0.docx    （重大改版）
```

輸出檔案存放於：`sdlc/fsd/output/`

## 9. 版本控制規則

| 版本類型 | 版號變更 | 觸發條件 |
|---------|---------|---------|
| 重大改版 | v**X**.0 → v**X+1**.0 | 範圍重大變更、系統重新設計 |
| 一般修訂 | vX.**Y** → vX.**Y+1** | 功能新增或修改 |
| 文字校正 | vX.Y → vX.Y（標注修訂）| 錯字、格式修正，不影響內容 |
